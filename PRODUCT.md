# Product Truth — Ratti to Carat (`rattitocarat.com`)

## Overview
A high-precision, distraction-free gemstone weight calculator and astrological reference tool. Built for gemstone buyers, jewelers, and Vedic astrology seekers in India, the Middle East, the UK, and the US.

## Purpose & Problem
- **The Problem:** Existing tools are bloated with intrusive e-commerce ads, use inaccurate rounded conversion ratios (`0.90` instead of certified `0.91`), and lack astrological context (*Sawa Ratti*, body-weight dosage).
- **The Solution:** An ultra-fast, mobile-first static tool web app with 0ms calculation latency, multi-unit breakdown, and clean non-repetitive multi-page tools.

## Operating Context & Audience
- **Primary Audience:** Indian gemstone buyers, astrologers, and jewelry traders (high mobile traffic, WhatsApp trade culture).
- **Secondary Audience:** Global international gem collectors converting between Metric Carats and traditional units.
- **Language:** Bilingual (English + हिन्दी).
