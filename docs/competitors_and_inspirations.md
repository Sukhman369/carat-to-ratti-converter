## Conversion Standard (Industry Consensus)

| Direction | Formula | Factor |
|---|---|---|
| Ratti → Carat | `Ratti × 0.91` | 0.91 |
| Carat → Ratti | `Carat × 1.09` | 1.09 |

> Note: "Ratti" is a traditional Indian unit (~180 mg). Not globally standardized — slight regional variations exist. International labs (GIA, IGI) always report in carats.

## What Ranks — Key Factors Summary

| Ranking Signal | Why It Matters |
|---|---|
| **Interactive JS calculator** | Increases time-on-page (key Google signal) |
| **Pre-built conversion tables** | Triggers featured snippets |
| **Educational explainer content** | Captures informational search intent |
| **Long-tail targeting** | "ratti for Ruby", "ratti for Neelam" etc. |
| **Mobile UX** | 70%+ traffic is mobile in India |
| **Domain authority** | Established gem/astrology sites dominate |
| **E-E-A-T signals** | Experience, expertise, authority, trust |
| **Fast load time** | Core Web Vitals — especially on mobile |
| **Astrology context** | Vedic audience is primary — not just gem traders |

## Gaps / Our Opportunity

- Most tools are **embedded in e-commerce sites** — no standalone, focused converter tool
- **Ratio inconsistency** across competitors (0.9 vs 0.91 vs 1.09 vs 1.10) — we can own accuracy
- **No tool shows multiple output units** (ratti + carat + grams + milligrams + grains) in one shot
- **No ADHD-friendly / minimal-distraction UI** — most pages are cluttered with ads/product pushes
- **No bilingual support** (Hindi + English) despite primary audience being Indian
- **No gemstone-specific presets** (e.g. "I need 5 ratti Ruby — what's that in carats?")
- **No shareable result URLs** or copy-to-clipboard for WhatsApp sharing (common in Indian gem trade)
